## 分辨率×帧率：为什么是 UNKNOWN

规格书只给出两个数：最高分辨率（C100 1920×1080 / C70 1280×720）和一句
`图像帧率：CIF:1-4 路 30 帧实时`。后者是安防 DVR 语境下的说法，不是 UVC 档位表；资料里
没有任何 `分辨率 → 帧率` 的枚举，也没有 MJPEG/YUYV 各自的带宽档位。传感器手册只保证满幅
30 fps 上限。因此本项不填推测值。

设备上枚举（唯一权威来源是 UVC 描述符本身）：

```bash
v4l2-ctl -d /dev/video0 --list-formats-ext   # 每种 fourcc 下的 frame size 与 frame interval
v4l2-ctl -d /dev/video0 --all                # 当前协商格式 + 全部控制项
```

实测帧率（协商值与真实值常不同，尤其 USB 2.0 带宽受限时）用本仓库的
`tools/camera_capture.py selftest`，它连拍并按单调时钟统计实际 fps。

预期结论（未验证，仅供对照实测）：USB 2.0 480 Mbps 下 1920×1080@30 必须走 MJPEG，YUYV 只能
跑到低分辨率档；具体档位以上面两条命令的输出为准。

## 相机内参（供畸变矫正起步用，非标定替代）

`相机内参.txt`，640×480 下（`fx, fy, cx, cy`）：

- C100：`302.7049, 302.2020, 298.6791, 234.9715`
- C70：`573.4945, 572.6848, 270.3346, 187.4165`

上表「FOV（推算）」即由这两组内参按
`H = atan(cx/fx) + atan((W−cx)/fx)`（V 同理）算得。

同一资料包内 `USB摄像头(ubuntu)代码工程/cam_usb_correct_python/camera_params.yaml` 里还有另一组
640×480 内参（`fx≈230.46, fy≈230.98, cx≈321.37, cy≈217.16`，推算 D 视场角 120.0°）。它与
`相机内参.txt` 的 C100 数据相差约 1.3 倍，**两者不可能描述同一取流档位**：前者更像 4:3 裁切窗口，
后者的 D120° 恰好对上 C100 标称对角视场。资料未说明各自对应哪种 UVC 档位，故不采信任何一组作为
定值——`相机标定、内参获取与畸变矫正/readme.txt` 原文即声明「内参数值只能表示大致数值……每个相机
内参都会有细微差别」，需自行标定。资料附 A4 标定板 `标定板A4_9x6_25mm.pdf`（内角 9×6，方格 25 mm）。

## 资料内部矛盾（选型/建模前需确认的项）

1. **C100 像元尺寸**：规格书 3.0 µm×3.0 µm vs GC2053 手册 2.8 µm×2.8 µm。1/2.9″ 上放 1920×1080
   个 2.8 µm 像元与 GC2053 手册自述一致，规格书该行疑为沿用 C70 的数值，但资料无法自证。
2. **C70 USB 线长**：§1 正文「输出线长为 1 m」vs §3 详细参数「自带 2.0 m USB 线」。
3. **C100 视场角**：详细参数 `H112°×V80°/D120°` vs 正文「对角线最大视角可达 120°」一致；但与
   `相机内参.txt` 推算的 D105.8° 不符（差异应来自取流档位裁切，资料未说明）。
4. **C70 视场角**：详细参数 `H85° V47°` vs 正文「对角线最大视角可达 80°」——H85° 已大于 D80°，
   两者不能同时成立。内参推算为 H58.0°/V45.2°/D69.8°，其中 V 与标称 V47° 接近而 H 差异极大，
   与「640×480 是 16:9 视场的水平裁切」相符。C70 规格书 V1.3（2025-11-12）的更新说明正是
   「修改视场角度」，说明该项厂商自己也改过。
5. **C100 暗处曝光闪白**：属已知缺陷，资料 `4.` 目录给出固件修复包。锁定曝光参数前应先按
   `操作方法.txt`（接 PC → 运行 `ACamMP.exe` → `Upgrade FM`）确认固件已更新，否则暗处曝光行为
   不可复现。该工具为 Windows only。

## UNKNOWN 汇总与获取办法

| UNKNOWN 项 | 获取办法 |
| --- | --- |
| 分辨率×帧率档位表 | `v4l2-ctl -d /dev/video0 --list-formats-ext` |
| 实际可持续帧率 | `python tools/camera_capture.py selftest`（连拍 100 帧统计） |
| 最近对焦距离 | 资料无。实测：标定板逐步靠近直至 MTF 明显下降，记录临界距离 |
| 对焦形式（定焦/可调） | 目视镜筒是否有调焦螺纹与点胶；`v4l2-ctl -l` 是否出现 `focus_absolute` |
| C100 PCB 板宽、两机型安装孔中心距、C100 外壳安装接口 | 量 `3.三维模型/*.stp` |
| 支持的控制项及其 min/max/step/default | `python tools/camera_capture.py list`（或 `v4l2-ctl -d /dev/video0 -L`） |
| VID/PID、UVC 版本 | `lsusb -v -d <vid:pid>`；资料未给出 VID/PID |

参数锁定（关自动曝光/白平衡/增益/对焦）见 [`PARAM_LOCK.md`](PARAM_LOCK.md)。
