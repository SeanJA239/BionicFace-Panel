## 待补测量

**ch8 死区起点**:`uv run python tools/jog_channel.py --channel 8 --step-deg 1`,
从 100° 起每步 1° 往上推,记录眼球停止运动的精确角度;再从中位附近确认
双眼正视前方时的实际角度。两个数确认后:`neutralApplied` 90→实测中位,
`maxApplied` 135→死区起点。注意:多个预设的 ch8 是非零值(惊讶 1.0、悲伤
0.5 等),它们以 neutral 为锚,改 neutral 会改变这些值的含义 -- 但由于上段
本来就是死区,物理行为不变,改完需逐个预设目视确认。

**ch12 参照系**(三选一,各自的修法):

1. **反于孪生脸** -- 推 ch12 时真实下眼睑与屏幕上孪生脸方向相反
   → 渲染器的 MIRRORED_CHANNELS 里 ch12 是错的,移除
2. **反于 ch10(左下眼睑)** -- 同方向推 ch10/ch12,两侧眼睑动作相反
   → 证实镜像装配,渲染器保留;control.rs 的 BLINK_CLOSE_DIRECTIONS 中
   ch12 的"高端=闭合"要翻转(该表本就标注 ch12 未确认),driver 的
   eyeBlinkRight 权重同步取反并重算偏置
3. **反于解剖预期** -- 系数增大时眼睑动作与"闭合"相反
   → 与 2 的修法相同,但不构成镜像证据
